Реализовать телеграм бота-помощника на модуле pyTelegramBotAPI, который будет:
- общаться с пользователем
- использовать для хранения всей информации о пользователе менеджер chroma_manager.py

Логика памяти бота: каждое сообщение векторизуется, после этого ищется максимальное схожее по смыслу в хрома:
- если информация новая и в БД нет такой информации, создаётся новая запись (текст+эмбеддинг)
- если найденное в БД по содержанию соответствует сообщению, то новая запись не делается
- если найденное в БД противоречит последней фразе пользователя, информация в БД обновляется
В векторе должен сохраняться только оригинальный текст сообщения от пользователя (user_message). Служебные поля вроде bot_response и полные шаблонные фразы ("Пользователь начал диалог о...") сохранять не нужно.

При построении ответа бота используется дополненный контекст из 5 (количество настраивается через .env) семантически схожих записях из БД

логирование в консоль о записи, обновлении, скипании инфо от пользователя (например: action: updated/skipped/created)
сразу реализуй запуск через docker-compose
проект учебный, предполагается минимальная нагрузка, асинхронность не нужна
